### Engineering mindset

- **Start with the problem.** Understand business rules and workflows before selecting a framework.
- **Keep complexity intentional.** Prefer readable code, explicit boundaries, and pragmatic architecture.
- **Protect data integrity.** Design relationships, constraints, validation, and error handling carefully.
- **Make work verifiable.** Document setup, implementation choices, and testing where relevant.
